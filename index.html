Finding a direction & bearing
How to convert a vector into a compass bearing (000°–360°)

The three-step method

1Sketch — Draw the vector on a compass diagram and identify its quadrant (NE/SE/SW/NW).

2Reference angle α — Use tan to find the acute angle between the vector and the nearest N–S line:

tan α = |horizontal component| ÷ |vertical component|

3Bearing — Bearings are always measured clockwise from North (000°). Adjust using the quadrant rule.

⚠ Use horizontal ÷ vertical (not vertical ÷ horizontal). Bearings are measured from North, so the N–S axis is the "adjacent" side of your reference triangle.

Worked example: v = −i − j

Step 1 — Quadrant

−i − j → 1 West, 1 South → SW quadrant

Step 2 — Reference angle

tan α = 1/1 = 1  →  α = 45°

Step 3 — Bearing

South = 180°. Vector is 45° west of South.

Bearing = 180° + 45° = 225°

Bearing rules by quadrant

Finding α — always positive

α is always acute (0°–90°). Use magnitudes — the negative signs only tell you the quadrant, not the angle size.

Magnitude (Pythagoras in 2D)
Finding the length of a vector using its components

Formula

|v| = √(a² + b²) where v = ai + bj

The magnitude is the length of the vector — always non-negative. This is just Pythagoras on the right-angled triangle formed by the components.

Worked example: v = 5i − 12j

|v| = √(5² + (−12)²)

= √(25 + 144) = √169 = 13

⚠ Common error: (−12)² = +144, not −144. Squaring removes the negative sign.

Speed from displacement (mechanics context)

speed = |displacement vector| ÷ time

Convert time to a single unit first — e.g. 2 h 45 min = 2 + 45/60 = 2.75 hours.

The triangle inequality
What it means geometrically when |a + b| = |a| + |b|

The key idea

When you add two vectors tip-to-tail, they normally form a triangle. The resultant is the closing side, which is shorter than the two sides added together: |a + b| < |a| + |b|.

If |a + b| = |a| + |b|, there is no triangle — the path is a straight line with no turning.

Exam answer (1 mark): "a and b are parallel and in the same direction" — they are collinear and point the same way, so placing them tip-to-tail forms a straight line.

The displacement rule
Finding |m − n| and angles using the sine and cosine rules

Key geometric insight

Rewrite m − n as m + (−n). Place tip-to-tail to form a triangle with sides |m|, |n| and |m−n|.

Crucial: if the angle between m and n is θ, the angle inside the triangle (at the tip of m, between m and −n) is 180° − θ.

The sine rule

sin A / a = sin B / b = sin C / c

Use when you know one side–angle pair and want to find another angle. Each fraction pairs a side with its opposite angle.

The cosine rule

a² = b² + c² − 2bc cos A

Use when you know two sides and the included angle (to find the third side), or all three sides (to find an angle).

Rearranged to find an angle:

cos A = (b² + c² − a²) / 2bc

In displacement triangles the internal angle is 180°−θ, so cos(180°−θ) = −cos θ — be careful with signs.

Decision guide: Right-angled triangle → Pythagoras or trig ratios. Non-right, know side + opposite angle → Sine rule. Non-right, no side-angle pair → Cosine rule.

Full worked example: |m|=3, |m−n|=6, angle between m and n = 30°

Find the angle between m and m − n.

Step 1 — Label the triangle

Vertices: O (origin), P (tip of m, |OP|=3), Q (tip of n). Side QP = m−n → |QP|=6. Angle at O = 30°. Required angle α is at P.

Step 2 — Sine rule at Q to find θ

sin θ / |OP| = sin(30°) / |QP|

sin θ / 3 = 0.5 / 6  →  sin θ = 0.25  →  θ = 14.5°

Step 3 — Angles sum to 180°

α = 180° − 30° − 14.5° = 135.5°

Angle between m and m − n = 135.5°

Vector geometry
Position vectors, proofs of collinearity, ratio of line segments

Vector between two points

AB⃗ = b − a

Subtract the position vector of the start from the position vector of the end.

Midpoint of AB

m = ½(a + b)

Average the two position vectors.

Proving collinearity

Show AB⃗ = λ · AC⃗ for some scalar λ. If parallel and sharing point A → all three points lie on one line.

Show AC⃗ = λ · AB⃗ → state "parallel vectors sharing point A → collinear"

Proving a path passes through the origin O

Show that AO⃗ = k · OB⃗ for some scalar k. Parallel vectors sharing point O → O lies on line AB.

Vector path method (parametric approach) for ratio problems

Write an unknown point N on line CM as: ON⃗ = OC⃗ + λ · CM⃗

If N also lies on another line (e.g. OB), equate coefficients to find λ. Then compute ON and NB to find the ratio.

ON⃗ = OC⃗ + λ·CM⃗ → N on OB means coeff of a = 0 → solve for λ → find ratio ON:NB

Q1 · Position vectors
A = 3i − 7j   B = 8i + 3j
4 marks

(a) Find the vector AB⃗  (2)

(b) Find |AB⃗|. Give your answer as a simplified surd.  (2)

📐 Theory: AB⃗ = b − a  |  |v| = √(x²+y²) → simplify surd
Part (a) — AB⃗ = b − a

AB⃗ = (8i + 3j) − (3i − 7j) = (8−3)i + (3−(−7))j = 5i + 10j

Part (b) — magnitude, then simplify surd

|AB⃗| = √(5² + 10²) = √(25 + 100) = √125 = √(25 × 5) = 5√5

AB⃗ = 5i + 10j     |AB⃗| = 5√5

Q2 · Position vectors
A = 4i − 5j   B = −5i − 2j
4 marks

(a) Find the vector AB⃗  (2)

(b) Find |AB⃗| as a simplified surd.  (2)

📐 Theory: AB⃗ = b − a  |  Simplify √90 = √(9×10) = 3√10
Part (a) — AB⃗ = b − a

AB⃗ = (−5i − 2j) − (4i − 5j) = (−5−4)i + (−2−(−5))j = −9i + 3j

Part (b) — magnitude

|AB⃗| = √((−9)² + 3²) = √(81 + 9) = √90 = √(9 × 10) = 3√10

AB⃗ = −9i + 3j     |AB⃗| = 3√10

Q3 · Triangle inequality & displacement
|m|=3, |m−n|=6, angle 30°
5 marks

(i) Two non-zero vectors a, b: |a+b|=|a|+|b|. Explain geometrically.  (1)

(ii) |m|=3, |m−n|=6, angle between m and n=30°. Find angle between m and m−n to 1 d.p.  (4)

📐 Theory: Displacement rule (Tab 4)  |  Sine rule  |  Triangle inequality (Tab 3)
Part (i)

a and b are parallel and in the same direction — placed tip-to-tail they form a straight line with no turning.

Part (ii) Step 1 — label the triangle

O = origin, P = tip of m (|OP|=3), Q = tip of n. Side QP = m−n (|QP|=6). Angle at O = 30°. Required angle α is at vertex P between the directions PO and PQ — this equals the angle between m and m−n.

Step 2 — sine rule at Q to find small angle θ

sin θ / |OP| = sin(30°) / |QP|

sin θ / 3 = 0.5 / 6 → sin θ = 0.25 → θ = arcsin(0.25) = 14.5°

Step 3 — angles sum to 180°

α = 180° − 30° − 14.5° = 135.5°

Angle between m and m − n = 135.5°

Q4 · Bearing & speed — coastguard
Start (4i−2j) km · End (−3i−5j) km · 10:00→12:45
6 marks

[i = due East, j = due North]

(a) Calculate the bearing of travel to 1 d.p.  (3)

(b) Calculate speed in km h⁻¹  (3)

📐 Theory: Bearings (Tab 1)  |  Speed = |displacement| ÷ time (Tab 2)
Step 1 — displacement vector

d = end − start = (−3i−5j) − (4i−2j) = −7i − 3j  → 7 km West, 3 km South → SW quadrant

Part (a) — bearing (SW rule: 180° + α)

α = arctan(|−7| / |−3|) = arctan(7/3) = 66.8°

Bearing = 180° + 66.8° = 246.8°

Part (b) — speed

Distance = |d| = √(7² + 3²) = √58 km

Time = 12:45 − 10:00 = 2 h 45 min = 2.75 h

Speed = √58 / 2.75 ≈ 2.77 km h⁻¹

(a) Bearing = 246.8°     (b) Speed = 2.77 km h⁻¹

Q5 · Stone on ice — passes through O
A(−24i−10j) m → B(12i+5j) m in 4 s
5 marks

[i = due East, j = due North]

(a) Prove the stone passes through O.  (2)

(b) Calculate speed.  (3)

📐 Theory: Parallel vectors share a point → collinear (Tab 5)  |  Speed = |AB| ÷ time (Tab 2)
Part (a) — show O lies on path AB

AO⃗ = −OA⃗ = −(−24i − 10j) = 24i + 10j

OB⃗ = 12i + 5j

AO⃗ = 2(12i + 5j) = 2 · OB⃗ ✓

AO⃗ is parallel to OB⃗ and they share point O → O lies on line AB. The stone passes through O.

Part (b) — speed

AB⃗ = B − A = (12−(−24))i + (5−(−10))j = 36i + 15j

|AB⃗| = √(36² + 15²) = √(1296 + 225) = √1521 = 39 m

Speed = 39 ÷ 4 = 9.75 m s⁻¹

(a) AO⃗ = 2·OB⃗ → O on path ✓     (b) 9.75 m s⁻¹

Q6 · Triangle OAB — ratio proof
OC⃗=2OA⃗, M=midpoint AB, line CM meets OB at N
6 marks

(a) Find CM⃗ in terms of a and b.  (2)

(b) Show ON⃗=(2−3λ/2)a+(λ/2)b.  (2)

(c) Hence prove ON:NB=2:1.  (2)

📐 Theory: Vector path method (Tab 5)  |  ON⃗=OC⃗+λ·CM⃗
Part (a) — find CM⃗

CA⃗ = OA⃗ − OC⃗ = a − 2a = −a

AM⃗ = ½AB⃗ = ½(b−a)

CM⃗ = CA⃗ + AM⃗ = −a + ½(b−a) = −(3/2)a + (1/2)b

Part (b) — ON⃗ = OC⃗ + λ·CM⃗

ON⃗ = 2a + λ(−(3/2)a + (1/2)b) = (2−3λ/2)a + (λ/2)b ✓

Part (c) — N on OB means coeff of a = 0

2 − 3λ/2 = 0 → λ = 4/3

ON⃗ = (2/3)b   NB⃗ = b − (2/3)b = (1/3)b

ON : NB = 2/3 : 1/3 = 2 : 1 ✓

(a) CM⃗ = −(3/2)a + (1/2)b     (c) ON : NB = 2 : 1 ✓

Q7 · Collinear proof
P, Q, R collinear; Q one-third from P to R
3 marks

Show that q = ⅓(r + 2p).  (3)

📐 Theory: PQ⃗ = q − p  |  PQ = (1/3)PR → q − p = (1/3)(r − p)
Use PQ⃗ = (1/3)PR⃗

q − p = ⅓(r − p)

q = p + ⅓r − ⅓p = ⅔p + ⅓r = ⅓(2p + r) = ⅓(r + 2p) ✓

q = ⅓(r + 2p) ✓
